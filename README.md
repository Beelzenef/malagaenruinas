# Málaga es una ruina

Nací y crecí en Málaga, España, y espero acabar mis días en esta ciudad. Si las circunstancias me dejan.

Porque esta ciudad, vendida al exterior como un paraíso soñado, es cada vez más un infierno para sus nativas. Deshaucios, barriadas abandonadas en servicios mínimos, rentismo asfixiante, árboles y jardines descuidados...

Desde diferentes medios, [se reúnen aquí noticias que demuestran que Málaga está en ruinas](https://beelzenef.github.io/malagaenruinas/), cedida al mejor postor y olvidada para quienes la vivimos.

Este proyecto nace de la frustración como ciudadana, pero evolucionará con la esperanza de futuros mejores.
